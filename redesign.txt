## 1. PROJECT CONCEPT

SkillSwap is a peer-to-peer skill exchange platform where users teach skills they know and learn skills they want in return, without exchanging money.

Example:
- One user teaches Figma and wants to learn JavaScript.
- Another user teaches JavaScript and wants to learn Figma.
- The platform recommends them as potential skill-exchange partners.

The main workflow is:

Register → Create Profile → Add Skills → Discover Matches → Connect → Schedule Sessions → Exchange Skills → Give Reviews.

Keep the platform focused on this concept.
